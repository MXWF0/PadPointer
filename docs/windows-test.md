# Windows 手工验收

记录 Windows 版本、手柄型号与连接方式。使用便携包在交互式桌面逐项检查。

| 操作 | 预期 |
| --- | --- |
| 启动后插入手柄，逐一按标准键 | 首页报告真实槽位和状态 |
| 慢推和全推左摇杆后回中 | 低速可精细控制，回中停止 |
| 上下、左右推右摇杆 | 页面垂直、水平滚动 |
| 单击 A、B，连续按 A 两次 | 左键、右键、双击 |
| 按住 A 推动摇杆后松开 | 拖拽窗口并释放 |
| 按 View、Menu、Y、LB、RB | 桌面、开始菜单、任务视图和标签切换 |
| 录制组合键，分别绑定单击、双击、长按和持续 | 动作无冲突，重启保留设置 |
| 添加游戏 EXE，切入、Alt+Tab 离开、切回和退出 | 游戏前台暂停，桌面恢复 |
| 拖拽时切游戏，按住 A 回桌面 | 释放拖拽，待松开后重新按下才触发 |
| 拔出手柄再接回，切换槽位，睡眠并恢复 | 无持续输入，重连或恢复后可继续使用 |
| 关闭主窗口，再点托盘或二次启动 | 后台常驻，唤醒同一实例 |
| 托盘退出，重启便携版 | 进程停止，设置保留 |
| 注册已占用热键，随后换为可用热键 | 界面报告失败，修改后可注册 |
| 启用登录自启动和隐藏启动 | 登录后使用同一配置，按选项显示窗口 |

分别测量窗口显示、托盘隐藏以及连接手柄的空闲状态。CPU 为进程累计 CPU 时间增量除以采样时间和逻辑处理器数，内存同时记录工作集与私有内存。录制实机鼠标和游戏模式切换时记录采样方法、窗口类型和手柄型号。
## 本次验收记录

2026-11-16，Windows 11 26H2（Build 26300.9974），16 个逻辑处理器。程序报告 XInput 槽位 0 已连接，手柄型号未记录。

### v0.1.1 界面走查

在 125% 缩放、1000×680 与 1180×800 两种窗口尺寸下检查，截图见 [界面设计说明](ui.md)。

| 操作 | 预期 |
| --- | --- |
| 依次切换 跟随系统／浅色／深色 | 页面、控件、标题栏同时切换，无残留深色块或浅色描边 |
| 拖动窗口到最小尺寸 | 首页读数块、游戏行、设置行不重叠，内容可滚动 |
| 125% / 150% 显示缩放 | 图标清晰，卡片标题与按钮文字不裁切 |
| 仅用键盘遍历 | Tab 可达导航、按钮、开关、滑杆与键位行；Enter／空格触发，焦点环可见 |
| 触发提示后点击关闭按钮 | 提示条消失，下一条提示到达时重新出现 |
| 添加含中文与长路径的游戏 | 名称可编辑，路径以省略号收尾，保存与删除按钮不被挤出 |
| 映射页选中不同按键 | 图示高亮、编辑区标题与动作同步，一览表跟随选中 |

通过 `cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、20 项自动化测试与 Windows x64 Release 构建。实机检查了 Slint 窗口、连接状态、默认热键暂停与恢复、调整灵敏度写入便携配置、关闭窗口后后台常驻、二次启动唤回同一窗口、主界面正常退出。自动切换的时间与重触发保护通过模拟测试，真实游戏前台切换和实体手柄送入目标应用的动作待验收。

| 已连接手柄且空闲 | 样本 | 整机 CPU | 平均工作集 | 平均私有内存 |

| 首页显示 | 约 10.13 秒 | 本次未记录到进程 CPU 时间增量 | 35.92 MiB | 11.17 MiB |
| 主窗口隐藏，桌面映射启用 | 约 10.16 秒 | 0.010% | 36.17 MiB | 11.20 MiB |

空闲采样来自同一 Release 配置的实机副本，随后调整了图上按键位置和模式日志。未测量持续摇杆输入、模式切换端到端延迟、无手柄后台 CPU 或其他机型。

使用相同源码和静态 CRT，保持 fat LTO 与其余 Release 参数一致，比较 `opt-level = "s"` 与 `opt-level = 3`。前者 EXE 为 9,532,928 字节，后者为 11,566,592 字节，便携版采用前者。两种优化等级间的 CPU 与实体鼠标响应差异尚未测量。依赖表只包含 Windows 系统 DLL，包括 `xinput1_4.dll`。
