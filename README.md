# PadPointer

**用手柄操作 Windows 桌面 —— 轻量的手柄触控板**

[![Release](https://img.shields.io/github/v/release/MXWF0/PadPointer)](https://github.com/MXWF0/PadPointer/releases)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-0078D6)

PadPointer 是一款面向 Windows 10和11 的轻量级手柄桌面控制工具，使用 Rust 和 Slint 开发，支持 Xbox 及其他兼容 XInput 的手柄。
单文件约 9.5 MB · 后台内存约 15 MB · 空闲 CPU ≈ 0.01%

## ✨ 功能特性
-  左摇杆移动鼠标（径向死区 + 响应曲线 + 平滑），右摇杆垂直/水平滚动
-  16 个按键全部可自定义：鼠标键、双击、滚轮、键盘组合键（支持按键录制）
-  三种按键行为：原生（零延迟按住/拖拽）、按下触发、手势（单击/双击/长按/持续）
-  精细 / 快速移动修饰键，按住即变速
-  游戏自动识别：前台匹配游戏 EXE 即暂停映射，回桌面自动恢复；也可手动锁定模式
-  全局热键一键暂停/恢复（默认 `Ctrl+Alt+F12`）
-  托盘常驻、开机自启、隐藏启动、浅色/深色/跟随系统主题
-  配置导入导出；便携模式解压即用；配置损坏自动备份并恢复默认
-  纯本地运行，无网络、无遥测；MIT 开源

## 🎮 默认键位
| 手柄 | 功能 | 手柄 | 功能 |
|---|---|---|---|
| 左摇杆 | 移动鼠标 | 右摇杆 | 滚动页面 |
| A | 鼠标左键（按住拖拽） | B | 鼠标右键 |
| X | Alt+←（后退） | Y | Win+Tab（任务视图） |
| View | Win+D（显示桌面） | Menu | Win（开始菜单） |
| LB / RB | 切换标签页 | 十字键 | 方向键 |
| LS | 鼠标中键 | RS / LT / RT | 未绑定（推荐 LT = 精细移动） |

## 📥 下载与安装
从 [Releases](https://github.com/MXWF0/PadPointer/releases) 下载（附 SHA256 校验值）：
- **安装版** `Setup.exe`：当前用户安装，无需管理员权限，含开始菜单与卸载项
- **便携版** `Portable.zip`：**完整解压**后运行 `PadPointer.exe`，配置保存在 exe 旁的 `data\` 目录

> ⚠️ 首次运行若出现 SmartScreen 提示：本程序未购买代码签名证书，点击"更多信息 → 仍要运行"。源码完全公开，可自行构建核对。

配置与日志位置：安装版 `%APPDATA%\PadPointer\`，便携版 `exe目录\data\`。

## 🚀 快速上手
1. 连接 Xbox / XInput 兼容手柄，启动 PadPointer
2. 推左摇杆移动光标，A 单击 / 按住拖拽，B 右键
3. 在"按键映射"页点击手柄图上的任意按键即可改绑；"设置"页调节灵敏度

## 🕹️ 游戏模式
- **自动（默认）**：在"游戏"页添加游戏 EXE（按完整路径或仅文件名匹配，也可从运行中的进程挑选）。游戏进入前台 → 立即暂停桌面映射；回到桌面 → 短暂延迟后恢复。无法确认前台进程时**宁可暂停**，避免误注入。
- **手动**：托盘或主界面可锁定桌面/游戏模式；全局热键随时暂停/恢复。
- 切换模式时自动释放所有按住的键鼠，摇杆回中前不移动光标，杜绝"拖拽残留"。

## 👆 按键行为与手势
| 模式 | 说明 |
|---|---|
| 原生 | 按下即生效、松开即释放，零延迟，适合鼠标键与单键（拖拽） |
| 按下触发 | 每次按下触发一次动作（组合键、滚轮等） |
| 手势 | 同一按键区分单击 / 双击 / 长按 / 持续按住 |

> 手势模式下若绑定了双击，单击需等待"双击间隔"（默认 260ms）确认后才触发；追求零延迟请用原生模式。长按阈值默认 500ms，均可调整。

## ⚙️ 参数调优
| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| 指针速度 | 1350 px/s | 100–5000 | 全推摇杆时的光标速度 |
| 摇杆死区 | 0.15 | 0.02–0.6 | 摇杆漂移就调高 |
| 响应指数 | 1.6 | 0.5–4 | 越大慢推越精细 |
| 平滑时间 | 14 ms | 0–80 | 越大越顺滑但越"肉" |
| 精细 / 快速倍率 | 0.35× / 2× | — | 绑定到按键后按住生效 |
| 手柄轮询 | 8 ms | 4–32 | 越小越跟手 |

💡 建议关闭 Windows"提高指针精确度"（设置 → 鼠标 → 其他鼠标选项 → 指针选项），手感更一致。

## 🎮 手柄兼容性
- ✅ Xbox 360 / One / Series 及一切 XInput 兼容手柄（含多数国产手柄的 XInput 模式）
- ⚠️ PS / Switch Pro 手柄需先经 DS4Windows、Steam Input 等虚拟为 XInput 设备
- ⚠️ Xbox 指南键被系统保留，XInput 无法读取

## ❓ 常见问题
**管理员窗口 / UAC 界面无法操作？** 以管理员身份运行 PadPointer 可覆盖提权窗口；UAC 安全桌面是系统限制，任何同类工具都无法注入。
**游戏里光标还在动？** 把该游戏 EXE 加入游戏列表（无边框窗口游戏同样有效），或手动切游戏模式。
**杀毒软件报警？** 输入模拟类工具易被启发式误报；程序无网络行为，可校验 SHA256 或自行构建。
**单击感觉慢？** 该键绑定了双击所致，见上文手势说明，改用原生模式即可。

## 🔨 从源码构建
需要 Rust ≥ 1.85（edition 2024）与 VS Build Tools（MSVC）：
```powershell
cargo build --release          # 日常构建
cargo test                     # 20 项单元测试
.\scripts\build-release.ps1    # 静态 CRT + 第三方许可 + 便携包
.\scripts\build-installer.ps1  # NSIS 安装版（需安装 NSIS）
```
注：仓库内置 softbuffer 补丁版本（`vendor/softbuffer`，经 `[patch.crates-io]` 引入）。
